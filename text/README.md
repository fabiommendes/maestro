`teach.text`
============

A simple library and command line tool to manipulate exercises based on text analysis.


## Installation

Just `pip install teach.text` or use `flit install -s` from the project root if you want to help developing it from this repository.


## CLI Usage

Type `hey-text --help` on the terminal for help. It has several options to grade data and present it in a suitable format.

## Library

In most cases, `import teach.text` and use one of the classes:

* `IoQuestion()`
* `PatternQuestion()`
