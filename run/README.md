`teach.run`
==========

A simple library for running scripts.


## Installation

Just `pip install teach.run` or use `flit install -s` from the project root if you want to help developing it from this repository.


## CLI Usage

Type `hey-run --help` on the terminal for help. It has several options to grade data and present it in a suitable format.

## Library

In most cases, `import teach.run` and use one of the functions:

* `groups()`
* `questions()`
* `questions_dataframe()`.
