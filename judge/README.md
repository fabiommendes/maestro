`teach.lineperm`
================

A simple library and command line tool to manipulate exercises based on line permutations of code snippets.


## Installation

Just `pip install teach.lineperm` or use `flit install -s` from the project root if you want to help developing it from this repository.


## CLI Usage

Type `hey-lineprm --help` on the terminal for help. It has several options to grade data and present it in a suitable format.

## Library

In most cases, `import teach.lineperm` and use one of the functions:

* `groups()`
* `questions()`
* `questions_dataframe()`.
